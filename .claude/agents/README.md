# 조작대상 찾기 — 세 팀

정전조작 자료는 **하나라도 빠지면 현장에서 사람이 다친다.** 그래서 만드는
일과 검사하는 일을 나눠 두었다. 만든 사람이 제 것을 검사하면 제가 믿는
것을 또 믿는다 — 실제로 자료를 통째로 지울 뻔한 SQL 을 만든 쪽은 못 보고
검사하는 쪽이 찾아냈다.

| 팀 | 에이전트 | 하는 일 | 고치나 |
|---|---|---|---|
| **만드는 팀** | `redtag-builder` | SQL 과 화면을 실제로 만든다 | 고친다 |
| **검사하는 팀** | `redtag-data-auditor` | 원본 배치 ↔ 사본 ↔ 실물 DB 를 id 단위로 대조. 누락·초과·오기·되살아날 위험 | 안 고친다 |
| | `redtag-ux-reviewer` | 폰에서 한 손으로 쓸 수 있는지. **자료에 있는데 화면에 안 나오는 것**이 최우선 | 안 고친다 |
| **검증하는 팀** | `redtag-drawing-verifier` | 설계도서·벤더도서 원본 PDF 를 직접 읽어, 피더가 도면과 맞는지 | 안 고친다 |

## 흐름 — 검사 → 검증 → 만들기

```
  ① 검사하는 팀        ② 검증하는 팀             ③ 만드는 팀
  ─────────────       ─────────────            ──────────
  자료끼리 안 맞는 데,   그게 정말 틀린 건지       도면이 맞다고 한 것만
  빠진 데를 찾는다  ──→  도면으로 확인한다   ──→  고친다
  (원본↔DB↔화면)       (도면 ↔ DB)
                             │
                             └──→ 애매하면 ★사용자에게 물어본다★
                                  (도면이 없거나, 도면끼리 다르거나,
                                   둘 다 맞을 수 있을 때)
```

**검사하는 팀**은 **자료끼리** 맞는지 본다(원본 ↔ DB ↔ 화면).
**검증하는 팀**은 **자료가 현실과** 맞는지 본다(도면 ↔ DB).
둘은 다른 질문이다. 배치 파일끼리 완벽히 일치해도, 그 배치가 도면을
잘못 읽었으면 틀린 것이다.

### 규칙
- 검사팀이 찾아낸 것은 **검증 없이 바로 고치지 않는다.** 도면으로 확인한 뒤 고친다.
  (예외: 오기·빠진 연결처럼 원본 확정 자료에 답이 이미 적혀 있는 것)
- 검증팀이 **확실**로 판정하면 → 만드는 팀이 바로 고친다.
- 검증팀이 **추정**이거나 **확인 못 함**이면 → **사용자에게 묻는다.** 지어내지 않는다.
- 도면끼리 다르면 → 최신 Rev 를 밝히고, 그래도 갈리면 사용자에게 묻는다.
- 만드는 팀은 **검사·검증 결과를 반영하는 것이 주 업무**다. 제 판단으로
  자료를 바꾸지 않는다.

## 도면 색인

11,071건을 매번 훑지 않도록 색인을 떠 두었다.

```
python -I .redtag-index/find.py MCC SCHEDULE
python -I .redtag-index/find.py --elec GSUT
python -I .redtag-index/find.py --ext pdf --root VDCL 52CG
```

색인을 다시 뜨려면 `.redtag-index/build_index.py` 를 돌린다(파일이 늘었을 때).

**⚠️ 전기 도면은 '전기분야' 폴더에만 있지 않다.** 기계·계측제어·토목 폴더에도
2,761건이 흩어져 있다 — VDCL 기계분야에만 354건. 제목에 `ELEC`·`단선도`·
`SCHEMATIC`·`MCC`·`PANEL` 이 들어가면 전기 자료다. `--elec` 는 폴더가 아니라
제목·경로의 낱말로 가려내므로 그런 것까지 잡는다.

## 되풀이된 함정

- **PostgREST 는 한 번에 1,000행까지.** `range()` 로 끝까지 나눠 받아라.
  이것 때문에 6.9kV 전체가 목록에서 통째로 빠졌었다.
- **건수만 세면 안 된다.** 합계가 같아도 서로 다른 것이 빠지고 들어와
  상쇄된다. id 를 하나하나 맞춰라.
- **`delete`·`update` 에 `where` 가 빠지면 끝장이다.**
- **원본에 없는 수정은 배치 재생성 때 되살아난다.** 고쳤으면 원본에도 심어라.
- **이름을 통째로 찾으면 못 찾는다.** `SUT Cooling Fan` 으로
  `SUT. Cooling FAN` 이 안 잡혔다 — 마침표 하나 때문에.
