# 무인 실행 — 컴퓨터만 켜 두면 알아서

세 팀(만들기·검사·검증)을 큐에 따라 쉬지 않고 돌린다.
**토큰이 떨어지면 리셋 시각까지 자고 같은 일을 다시 한다.** 사람이 지켜보지
않아도 이어 간다.

## 왜 이 PC 에서 도는가
도면이 `C:\업무자료` 에 있다. 클라우드 에이전트는 이 폴더를 못 읽는다.
그래서 **반드시 이 컴퓨터에서** 돌아야 한다.

## 설치

```powershell
powershell -ExecutionPolicy Bypass -File automation\install.ps1
```

등록되는 것 둘:
- `RedTag-팀-무인실행` — 로그인할 때 뜬다
- `RedTag-팀-살아있나` — 5분마다 꺼졌는지 보고 다시 띄운다

해제는 `install.ps1 -Remove`.

## 일 시키기 — queue.json 에 적는다

```json
{
  "id": "짧은-이름",
  "title": "사람이 읽을 제목",
  "status": "pending",
  "model": "opus",
  "prompt": "무엇을 어떻게 해 달라고 쓴다. 어느 팀을 쓸지도 적는다."
}
```

`status` 가 `pending` 인 것을 위에서부터 하나씩 집어 간다.
끝나면 `done`, 실패하면 `failed`, 한도에 걸려 기다리는 중이면 `waiting_limit`.

큐가 비면 10분마다 다시 본다 — **돌아가는 중에 일을 더 적어 넣어도 된다.**

## 멈추기
`automation\STOP` 이라는 빈 파일을 만든다. 하던 일만 끝내고 선다.
지우면 다음 확인(5분 안)에 다시 뜬다.

## 기록
- `automation\logs\runner-YYYYMMDD.log` — 언제 무엇을 했나
- `automation\logs\<일이름>-<시각>.json` — 그 일의 전체 결과
- `queue.json` 의 `summary` 칸에 보고 앞머리 1,200자

## 토큰 한도를 만나면
1. 한도 안내에서 **리셋 시각**을 읽는다 (`reset at 3pm` / 유닉스 초 둘 다 읽음)
2. 그때까지 잔다 (+2분 여유). 못 읽으면 45분
3. 깨어나 **같은 일을 처음부터** 다시 한다 — 한도는 실패로 세지 않는다

그동안 `queue.json` 의 그 일은 `waiting_limit` 이고 `resume_at` 에 깨울 시각이 적힌다.

## ⚠️ 권한에 대해 — 알고 쓰세요

무인으로 돌려면 사람이 "예"를 눌러 줄 수 없으므로
`--permission-mode bypassPermissions` 로 돈다. 즉 **묻지 않고 한다.**

대신 돌이킬 수 없는 것은 막아 두었다:

```
Bash(git push:*)        원격에 올리지 못한다
Bash(git reset --hard:*)
Bash(rm -rf:*) / rmdir /s / del /f / format
```

그리고 구조상 더 막혀 있는 것:
- **SQL 을 실행할 수 없다.** 앱이 쓰는 키는 `SELECT` 권한만 있다.
  자료를 고치는 SQL 은 파일로 쓰기만 하고, 사람이 Supabase 에서 돌린다.
- **원격에 못 올린다.** 커밋까지만 한다. `git push` 는 사람이 한다.
- 검사팀·검증팀 에이전트는 애초에 쓰기 도구가 없다(읽기만).

그래도 **이 PC 의 파일을 고칠 수는 있다.** 저장소는 git 으로 되돌릴 수 있지만,
`C:\업무자료` 의 도면은 그렇지 않다 — 다만 에이전트들에게 읽기만 하라고
일러 두었고, 지금까지 그 폴더를 고친 적은 없다.

불안하면 `run-redtag.ps1` 의 `--permission-mode` 를 `acceptEdits` 로 바꾸면
파일 수정은 자동, 명령 실행은 막힌다(대신 일이 중간에 멈추는 일이 잦아진다).

## Aside 를 같이 쓰려면
에이전트는 Bash 로 `aside exec "..."` 를 부를 수 있다. 화면을 실제로 열어
확인해야 하는 일(배포 확인, 엑셀을 진짜 엑셀로 열어 보기)은 프롬프트에
"Aside 로 확인해 달라" 고 적어 두면 된다. Aside 는 사용자가 로그인해 둔
브라우저를 쓰므로, **컴퓨터가 켜져 있고 로그인돼 있어야** 한다.
