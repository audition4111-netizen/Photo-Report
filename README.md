# 사진대장 생성 Wep App

스마트폰 브라우저에서 앱 설치 없이 바로 쓸 수 있는 **사진대장(Photo Report) 작성 웹앱**입니다.
사진을 한 장씩(또는 여러 장) 추가하고 설명을 적으면, A4 규격 사진대장 문서를 자동으로 구성해 PDF로 출력하거나 메일로 보낼 수 있습니다.

🔗 **바로 사용하기**: https://audition4111-netizen.github.io/Photo-Report/

## 주요 기능

- 파일명 입력 후 PDF 출력
- 스마트폰 사진 앨범에서 사진 추가 (한 장 또는 여러 장 한 번에 선택, 최대 30장)
- 사진별 설명 입력 (여러 줄 지원, 자동 높이 조절, 출력 시 가운데 정렬)
- 사진 변경 / 90도 회전 / 삭제
- [순서 이동]을 눌러 옮길 순번을 선택하는 방식으로 사진 순서 변경
- A4 세로 페이지에 사진 4장(2×2)씩 자동 배치, 5장부터 다음 페이지 자동 생성
- A4 미리보기 (실제 출력과 동일한 레이아웃)
- **PDF 출력**: 실제 PDF 파일 생성, 스마트폰에서 바로 다운로드
- **메일로 전송**: PDF를 자동 다운로드하면서 Gmail 작성 화면을 새 탭으로 열어줌 (첨부는 Gmail 화면에서 직접 추가)
- **문서 보관함(선택)**: 로그인하면 출력한 PDF가 자동 저장되고 나중에 조회 가능
  → 설정 방법은 [SUPABASE-SETUP.md](SUPABASE-SETUP.md)
- 보관함을 설정하지 않으면 서버/DB/로그인 없이 브라우저 안에서만 동작
- 작성 중 [임시저장]을 누르면 앱을 닫아도 이어서 작성 가능 (기기 안에 보관, 서버로 올라가지 않음)
- **앱으로 설치해서 사용 가능** (아래 참고)

## 앱으로 설치하기

브라우저 즐겨찾기가 아니라 **홈 화면 아이콘이 있는 앱**으로 설치됩니다.
설치하면 주소창 없이 전체화면으로 열리고, 신호가 약한 곳에서도 켜집니다.

| 기기 | 방법 |
|---|---|
| **Android** (Chrome / 삼성 인터넷) | 사이트 접속 → 하단이나 메뉴(⋮)의 **[앱 설치]** / **[홈 화면에 추가]** |
| **iPhone / iPad** (Safari) | 사이트 접속 → 공유 버튼 <kbd>⇧</kbd> → **[홈 화면에 추가]** |
| **PC** (Chrome / Edge) | 주소창 오른쪽 **설치 아이콘(⊕)** 클릭 |

> ℹ️ iPhone은 **Safari로 접속해야** 홈 화면에 추가할 수 있습니다. Chrome 등 다른
> 브라우저에서는 메뉴에 항목이 나타나지 않습니다.

설치 후 업데이트는 **자동**입니다. 앱을 열 때 새 버전이 있으면 바로 받아 옵니다.
(따로 재설치할 필요 없습니다)

### 오프라인 동작 범위

| 기능 | 인터넷 없이 |
|---|---|
| 문서 작성 · 사진 추가 · 편집 · 미리보기 · PDF 출력 | ✅ 됩니다 |
| 임시저장 · 이어서 작성 | ✅ 됩니다 |
| 로그인 · 보관함 저장 · 보관함 조회 · 메일 전송 | ❌ 인터넷 필요 |

## 사내망용 단일 파일 (`뚝DOC-사내망.html`)

인터넷이 닿지 않는 사내망에서 **HTML 파일 하나만 주고받아** 쓰는 버전입니다.
서버도 인터넷도 필요 없고, 파일을 더블클릭하면 바로 열립니다.

| | 웹 버전 | 사내망 단일 파일 |
|---|---|---|
| 로그인 | 필요 | **없음** (누구나 바로 작성) |
| 보관함 저장·조회 | ✅ | **없음** |
| 개선요청 게시판 | ✅ | **없음** |
| 메일로 전송 | ✅ | **없음** |
| 작성 · 사진 편집 · 미리보기 · **PDF 출력** | ✅ | ✅ |
| 임시저장 · 이어서 작성 | ✅ | ✅ (그 PC 브라우저에 보관) |

**받는 방법**: 이 저장소에서 `뚝DOC-사내망.html` 을 내려받아 그대로 전달하면 됩니다.
다른 파일은 필요 없습니다 (라이브러리·이미지가 파일 안에 들어 있습니다).

**다시 만들 때**: `index.html` 을 고친 뒤 아래를 실행하면 갱신됩니다.

```bash
node build-standalone.js
```

> ⚠️ 임시저장은 **파일을 연 그 PC의 브라우저에** 저장됩니다. 파일을 다른 사람에게
> 보내도 작성 중이던 내용은 따라가지 않습니다. 완성된 문서는 PDF 로 출력해 주고받으세요.

## 사용 방법

1. 파일명을 입력합니다.
2. [사진 추가]로 사진을 한 장 또는 여러 장 선택합니다.
3. 사진 아래에 설명을 입력합니다. (최대 30장까지 반복)
4. 필요하면 변경 / 회전 / 삭제, 드래그로 순서 변경을 합니다.
5. [미리보기]로 A4 페이지 구성을 확인합니다.
6. [PDF 출력]으로 다운로드하거나, [메일로 전송]으로 PDF 다운로드 + Gmail 작성 화면을 한 번에 엽니다.

## 만든이의 사용 가이드 추천사항 ##

1. 물품 구매 후 ERP 첨부의 사진대장 작성 시 사용
 - 작성된 사진대장을 [메일로 전송]을 통해 회사메일로 전송
 - 자료 교환 후 ERP 첨부로 사용

2. 모바일 홈 화면에 배치하여 사용
 - 휴대폰 검색으로 [브라우저] 실행 후 **바로 사용하기의 주소를 복사하여 실행
 - 실행화면의 우측 하단 눌러 [현재 페이지 추가]-[홈 화면]으로 저장
